# Painel de campo

Uma mesa de decisão (importante × urgente), notas e tarefas, para usar no celular.

- **Sem servidor e sem conta.** O que você escreve fica no seu aparelho.
- **Abre sem internet** depois da primeira vez.
- **Instalar:** abra no navegador do celular e escolha "Adicionar à tela inicial".
- **Enviar uma nota** gera um link. O texto vai depois do `#`, que não é enviado a servidor nenhum.
- **Guardar cópia** e **trazer cópia** ficam nos três pontinhos. Trocar de aparelho sem cópia zera.

São arquivos parados (HTML, JS e dois ícones): cabem numa pasta de qualquer servidor web.
